# super-duper-train

Juiced Up with VS Code and GitHub Copilot.

## Getting Started

Open this repository in [Visual Studio Code](https://code.visualstudio.com/). When prompted, install the recommended extensions:

- **GitHub Copilot** – AI pair programmer
- **GitHub Copilot Chat** – Conversational AI assistant

VS Code will automatically suggest these extensions from `.vscode/extensions.json`.

## GitHub Copilot

GitHub Copilot is enabled for all file types in this repository via `.vscode/settings.json`. Sign in to your GitHub account in VS Code to activate it.
